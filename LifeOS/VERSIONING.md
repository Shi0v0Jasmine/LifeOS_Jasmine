# LifeOS — 版本管理（VERSIONING）

Current source version: `5.0.2`
Latest released version: `5.0.2`（2026-07-24 发布，移动端子任务表单纤细化）

版本号格式：

```text
大版本.小版本.bug修复
```

## 大版本（MAJOR）

加入新功能（新的主流程/新模块），或整个项目重构时 +1。

LifeOS 示例：

- 新增番茄钟、月视图、循环事件等时间轴主流程
- 新增子任务系统、本机 Express 后端、AI 任务拆解
- 新增多端云同步模块
- 前端整体重构（如迁移到构建式框架）

## 小版本（MINOR）

在原项目基础上的小修小补：主流程不变，能力范围拓展时 +1。

LifeOS 示例：

- 数据导入导出支持的格式扩展（如从 JSON 拓展到 CSV）
- 新增一种统计图表、新增一个设置项
- 某页面增加辅助功能（习惯补打卡这类）
- 移动端响应式适配（不改变主流程，拓展使用场景）

## bug修复（PATCH）

字面意义：碰到 bug 修一下。文档修正、样式微调也算。

LifeOS 示例：

- 修复 Vue Proxy 序列化导致的保存失败
- 修复循环事件虚拟实例编辑异常
- 修复统计缓存未随日期切换清空
