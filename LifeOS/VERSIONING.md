# LifeOS — 版本管理（VERSIONING）

Current source version: `5.3.0`
Latest released version: `5.3.0`（2026-07-25 发布，习惯打卡成果度量 + 截图 AI 解析 + 数据面板）

版本号格式：

```text
大版本.小版本.bug修复
```

## 大版本（MAJOR）

**全新功能模块/页面级插入**（从 0 到 1），或整个项目重构时 +1。

LifeOS 示例：

- 新增「学习」模块的技能树页面
- 新增「时间轴」模块及其主流程
- 前端整体重构（如迁移到构建式框架）

## 小版本（MINOR）

**既有板块的功能追加**：主流程不变，在现有模块上增加能力时 +1。

LifeOS 示例：

- 任务板块加入子任务功能
- 多端同步板块加入账号密码登录
- 设备管理板块加入休眠/唤醒/删除
- 数据导入导出支持的格式扩展
- 移动端响应式适配（不改变主流程，拓展使用场景）

> **规则变更说明（2026-07-25）**：此前「新功能即大版本」导致大版本号增长过快。自本日起，**仅全新模块/页面级插入才升大版本**，既有板块的功能追加一律升小版本。历史版本号（v3.0.0/v4.0.0/v5.0.0/v5.1.0 等）保持不变，后续发版按新规则执行。

## bug修复（PATCH）

字面意义：碰到 bug 修一下。文档修正、样式微调也算。

LifeOS 示例：

- 修复 Vue Proxy 序列化导致的保存失败
- 修复循环事件虚拟实例编辑异常
- 修复统计缓存未随日期切换清空
