## Quick Start（3 分钟上手）

如果你只想快速用起来，按下面 4 步走：

1. **打开设置页**：左侧边栏 → 设置。
2. **确认后端**：在「多端同步」卡片里，同步后端选择「腾讯云 CloudBase（国内）」，并填入你的 CloudBase 环境 ID（envId）。
3. **登录账号**：在「账号」卡片里输入用户名和密码，点击「登录」。成功后你会看到「已登录账号」。
4. **设为主设备**：登录后在「多端同步」卡片打开「本设备为主设备」开关（v5.3.1 起：登录 + 开关同时满足才是主设备）。设为主设备后，其他已登录设备会自动降级为常用设备。

> 没有账号？需要先在 CloudBase 控制台创建，详见下方「前置条件」。

## 账号登录是什么

LifeOS 是一款本地优先（Local-First）的应用：你的所有数据默认存在浏览器 IndexedDB 里，不依赖网络也能用。

账号登录解决的是**权限问题**，不是数据存储问题：

- **不登录**：你仍然可以正常使用 LifeOS，数据通过「匿名登录」同步到云端。
- **登录后**：你才有成为「主设备」的资格（再打开「本设备为主设备」开关即可），可以管理其他设备（休眠、唤醒、删除），并且在多端数据冲突且时间接近时，你的修改优先被保留。

简单说：**登录 = 你是这台设备的主人；不登录 = 你是普通访客**。

## 前置条件：在 CloudBase 控制台创建账号

LifeOS 的账号体系基于腾讯云 CloudBase。目前**不支持在 App 内注册**，需要先在控制台手动创建：

1. 登录 [腾讯云 CloudBase 控制台](https://console.cloud.tencent.com/tcb)。
2. 进入你的环境（如 `lifeos-xxx`）。
3. 左侧菜单选择「身份验证」→「用户管理」。
4. 点击「新建用户」，填写：
   - **用户名**：登录时使用的名字（如 `jasmine`）。
   - **密码**：登录密码。
   - **手机/邮箱**：选填，用于找回密码（当前版本未开放找回功能，仅作记录）。
5. 在「身份验证」→「登录方式」中，确认已开启「用户名密码登录」。

> 如果你已经有一个 CloudBase 账号但不确定密码，可以在控制台重置。

## 登录账号

### 步骤

1. 打开 LifeOS，进入「设置」页面。
2. 在「多端同步」卡片中：
   - 同步后端选择 **「腾讯云 CloudBase（国内）」**。
   - 填入 **CloudBase 环境 ID（envId）**。
   - 点击「保存同步配置」。
3. 在「账号」卡片中：
   - 输入 **用户名** 和 **密码**。
   - 点击 **「🔑 登录」**。
4. 等待几秒，看到「已登录账号」和黄色「主设备权限」徽标即成功。

### 登录后会发生什么

- 页面顶部「账号」卡片显示你的 UID（用户唯一标识）。
- 「多端同步」卡片的「本设备为主设备」开关变为可用——打开它即成为主设备（v5.3.1 起为 AND 判定：登录 + 开关缺一不可；全局唯一，其他已登录设备自动降级）。
- 系统会自动触发一次数据同步，把本地数据推送到云端，并拉取云端最新数据。
- 设备心跳记录会写入 `accountUid`，方便你在设备列表里识别哪些设备属于这个账号。

## 登出账号

1. 进入「设置」→「账号」卡片。
2. 点击 **「🚪 登出」**。
3. 确认弹窗后，你会看到「已登出」提示。

### 登出后会发生什么

- 账号登录态被清除，`accountUid` 从本地设置中删除。
- 系统自动降级为「匿名登录」，继续同步数据。
- 本设备失去主设备权限（除非你之前手动开启了「本设备为主设备」开关）。
- 设备列表中本设备的 `accountUid` 字段会变为空。

## 主设备权限说明

### 什么是主设备权限

主设备权限是 LifeOS 多端同步体系中的「管理员」身份，包含两项能力：

1. **设备管理**：在「设置」→「多端同步」→「设备管理」中，可以查看所有已登录设备（区分 主设备/常用设备/普通设备），并按设备状态操作：
   - **休眠**（在线设备）：暂停该设备的同步（它还能本地使用，但不再与云端交换数据）。
   - **唤醒**（已休眠设备）：恢复该设备的同步。
   - **删除**（软吊销）：该设备下次同步时会被拒绝；吊销记录保留 30 天可恢复，超期由主设备自动彻底清理。
   - **恢复**（已删除设备）：撤销吊销，设备可重新同步（需重新配置同步后端）。
   - **彻底删除**（已删除设备）：立即物理删除吊销记录（不影响任何业务数据）。

2. **冲突平局裁决**：当两台设备几乎同时（< 2 秒）修改同一条数据时，主设备的版本获胜。

### 主设备权限从哪里来

| 来源 | 说明 |
|------|------|
| **账号登录** | 登录 CloudBase 账号（前提条件） |
| **本机开关** | 「设置」→「多端同步」→「本设备为主设备」开关 |

> ⚠️ v5.3.1 起判定改为 **AND**：必须**同时满足**「已登录账号」+「本机开关打开」才是主设备。只登录不开关、或只开关不登录，都不是主设备。
>
> 另外主设备**全局唯一**：在某台设备上设为主设备后，其他已登录设备会自动降级为「常用设备」；如果本机被降级，本地开关会自动关闭。

### 主设备权限与 deviceId 的关系

- **deviceId**：每台浏览器/每个域名下自动生成的唯一标识，用于标记「这条数据是谁改的」。
- **主设备权限**：决定「谁能管理设备」和「冲突时听谁的」。

两者独立：deviceId 不变，主设备权限可以跟随账号在多设备间切换。

## 匿名登录：未登录时的默认状态

如果你没有登录账号，LifeOS 会自动使用 CloudBase 的「匿名登录」：

- 数据正常同步到云端。
- 你可以在多台设备间同步数据。
- 你**不能**管理其他设备（看不到设备管理按钮）。
- 冲突平局时，你的版本优先级低于已登录账号的设备。

匿名登录的 UID 与账号登录的 UID 不同，云端会通过 `accountUid` 字段区分。

## 多设备使用场景

### 场景 1：电脑 + 手机同时用

1. 在电脑和手机的浏览器里都打开 LifeOS 部署地址。
2. 两边都配置同一个 CloudBase envId。
3. 在**主设备**（如电脑）上登录账号。
4. 手机端保持匿名登录即可，数据会自动同步。

### 场景 2：换浏览器 / 清缓存后

- **未登录**：清缓存后 deviceId 会重新生成，主设备权限丢失，需要重新设置。
- **已登录**：重新打开页面后，SDK 会自动恢复登录态，主设备权限跟随账号保留。

### 场景 3：多个人共用一个环境

当前版本**不建议**多人共用一个 CloudBase 环境：

- 所有数据共享同一个数据库，没有用户隔离。
- 设备管理权限基于账号，如果多人都有账号，都能管理设备。
- 后续版本（F-115）计划收紧安全规则到 `auth.uid == 所有者uid`，实现真正的单用户隔离。

## 功能速览（v5.2 ~ v6.1 新增）

### 健康（独立页面）

- **健康报告**：从侧边栏进入「健康」→「健康总览」，可导入体检报告、化验单或体重秤报告。支持单份 PDF（最多 20 页）或 1–5 张 JPG/JPEG/PNG/WebP/GIF/BMP/HEIC/HEIF/TIFF 图片，单文件不超过 10MB。
- **自动解析与确认**：LifeOS 会先在浏览器中读取文本或转换报告页，再调用设置页配置的多模态 AI，提取报告日期、机构、指标、参考范围和状态。解析完成后必须人工核对，确认后才写入健康档案。
- **总览与趋势**：健康总览集中显示正常、关注、建议复查和待核对指标；同名数值指标累计两次后，可查看长期变化。报告档案支持查看、编辑和软删除。
- **原件隐私**：报告原件、PDF 页面图、餐食照片和运动截图仅在当前页面内存中参与解析，不写入 IndexedDB、本机 JSON 或云同步；仅保存用户确认后的结构化数据。
- **餐食记录**：进入「饮食与运动」后，选择早餐/午餐/晚餐/加餐，可上传照片并手动点击 AI 分析，也可从本地食物库搜索添加。保存前可核对食物、份量和热量。
- **运动与目标**：运动支持截图识别或手动填写；在「个人目标」中选择减脂、维持或增肌/增重，填写基础资料后会计算每日热量与宏量营养建议。
- **趋势与周报**：页面展示近 7 日摄入/运动消耗。上一自然周会自动生成营养复盘；没有 AI 配置时自动使用本地规则。
- **健康说明**：所有数值均为生活记录估算，不替代医生或营养师建议。

### 习惯：计划、暂停与度量（习惯页）

- **周期/限时计划**：编辑习惯时可挂计划——每周 N 次（自然周）、每月 N 次（自然月，均可选停止日），或限时 N 次（从今天起 ≤30 天窗口）。卡片上显示进度（如「本周 2/3」「剩 X 天」），限时到期未达成标「未达成」。
- **暂停**：卡片 ⏸ 按钮暂停习惯，**原因必填**（如伤病/生理期），时段选填（不填=无限期手动恢复；填了到期自动恢复）。暂停期间打卡按钮置灰，且**不计入完成率和连续天数**。
- **成果度量**：给习惯定义成果字段（数字/时长/文字，如「总分」「距离 km」「时长 时:分:秒」），打卡时选填；时长支持 `1:23:45`、`30:15` 等写法。
- **截图 AI 解析**：打卡弹窗里「📷 上传截图 AI 自动填写」，上传 Keep 等运动 App 截图，AI 自动识别距离/时长/配速/心率并回填，确认后保存。**截图只用于解析，不会保存图片**。需要设置页配置的 AI 模型支持视觉（多模态），否则提示解析失败可手填。
- **数据面板**：卡片 📊 按钮打开周/月/季/年图表，柱子/圆点可点击跳回当天。
- **习惯详情**：点击习惯卡片本身，打开详情弹窗——摘要 + 逐条打卡历史（最近 30 条），每条可直接编辑。

### 任务：统计与联动（任务页/时间轴）

- **📊 任务统计**：任务页头部「统计」按钮，按周/月查看每日完成数柱状图、完成率趋势折线、四象限分布。
- **任务 ↔ 时间轴联动**：勾选完成任务时，时间轴上关联的时间块会自动打勾（✓ 删除线样式）；撤回完成同步还原。

### 回顾：情绪月历（回顾页）

- 选择心情后可以填写「为什么是这个心情」（选填）。
- 页面底部新增**情绪月历**：每天的情绪以表情图标展示，点击日期直接回到当天的回顾。

### 移动端体验（v4.2.0）

- **底部导航栏**：手机上页面底部固定 8 个页面图标，一键切换（左上角汉堡菜单仍保留）。
- **任务页象限切换**：手机上四象限改为 Tab 切换，一次看一个象限。
- **弹窗贴底**：手机上所有弹窗从底部升起（bottom sheet），输入框字号加大避免 iOS 自动放大。

## 常见问题（FAQ）

### Q1：登录时提示「CloudBase 登录失败：用户名或密码错误」

- 检查用户名和密码是否输入正确（注意大小写）。
- 确认 CloudBase 控制台「身份验证 → 用户管理」中已创建该用户。
- 确认「身份验证 → 登录方式」中已开启「用户名密码登录」。

### Q2：登录后没有看到「主设备权限」徽标

- 刷新页面（Service Worker 可能有缓存）。
- 检查「多端同步」后端是否选择的是 CloudBase。
- 打开浏览器控制台，输入 `await LifeOS.Sync.getAccountInfo()`，确认返回的 `uid` 非空且 `isAnonymous` 为 `false`。

### Q3：登出后数据还在吗？

- 在。登出只是切换登录态，本地 IndexedDB 数据不会删除。
- 云端数据也不会删除，只是本设备失去主设备权限。

### Q4：可以注册新账号吗？

- 当前版本不支持 App 内注册，必须在 CloudBase 控制台手动创建。
- 这是设计选择：LifeOS 定位为单用户应用，账号由所有者自己管理。

### Q5：Passkey / 微信扫码登录什么时候支持？

- Passkey（F-116）已列入规划，但 CloudBase 原生不支持，需要云函数自定义票据 + WebAuthn 流程，工作量较大，本期未实现。

### Q6：手机端登录按钮点不动 / 页面显示不全

- 确认手机浏览器已开启 JavaScript。
- 尝试横屏或缩小页面比例。
- 如果问题持续，在「设置」→「数据管理」中导出 JSON 备份后，清除浏览器缓存重新打开。

### Q7：截图 AI 解析提示失败 / 没识别出字段

- 确认「设置 → AI 配置」里的模型支持**视觉（多模态）**，例如 Kimi 的视觉模型；纯文本模型无法看图。
- 截图尽量清晰、完整（包含数据区域）；识别结果会以表单预填方式呈现，可以手动修正后再保存。
- 解析失败不影响打卡，手动填写即可。

### Q8：暂停中的习惯为什么不算完成率？

- 这是设计如此（F-119）：暂停期间该习惯从完成率分母中剔除，连续天数也不会因为暂停中断。恢复后正常计入。

## 故障排除

### 问题：登录按钮一直转圈 / 提示超时

**可能原因**：
- CloudBase SDK 首次加载较慢（CDN 网络波动）。
- envId 填写错误，连到了不存在的环境。

**解决步骤**：
1. 检查 envId 是否正确（在 CloudBase 控制台「环境 → 概览」里复制）。
2. 等待 20 秒后重试。
3. 打开浏览器 DevTools → Network，查看 `cloudbase` 相关请求是否返回 200。

### 问题：登录后设备列表里没有本机

**可能原因**：
- 登录后自动同步尚未完成。
- 设备心跳写入失败。

**解决步骤**：
1. 在「多端同步」卡片点击「立即同步」。
2. 点击「设备管理」区的「刷新」按钮。
3. 如果仍没有，检查控制台是否有 `[LifeOS Sync] 设备心跳失败` 警告。

### 问题：换了电脑后数据不一样

**可能原因**：
- 新电脑的浏览器是第一次打开，需要先从云端拉取数据。
- 两台设备的同步时间差导致 LWW 合并结果不同。

**解决步骤**：
1. 在新电脑上配置相同的 envId，点击「立即同步」。
2. 如果数据冲突，进入「待处理冲突」队列手动选择保留版本。
3. 日常使用中，尽量在修改数据后等待 5 秒（自动 push 防抖时间）再切换设备。
