# LifeOS 多端同步 — 腾讯云 CloudBase 配置指南

> 适用场景：主要在国内使用 LifeOS，希望同步后端国内直连、速度快。
> 与 Supabase（国际版）二选一，设置页 → 多端同步 → 同步后端 切换即可。
> 两个后端的表结构同构，数据互不通用；切换后端后首次同步会把本机数据全量推送到新后端。

---

## 1. 注册并开通云开发

1. 打开 https://cloud.tencent.com/ ，注册账号并完成实名认证（个人认证即可）。
2. 进入 **云开发 CloudBase 控制台**：https://console.cloud.tencent.com/tcb
3. 点击「新建环境」：
   - 计费方式选 **按量计费**（个人同步用量极小，月费用通常为 0 元 ~ 几毛钱；新用户有免费体验额度）
   - 环境名称随意，如 `lifeos`
   - 地域建议选 **上海** 或 **广州**（国内访问快）

> 📷 截图位置：云开发控制台「新建环境」对话框

4. 创建完成后，在环境详情页记录 **环境 ID**（形如 `lifeos-1a2b3c4d5e`），这就是设置页要填的 envId。

> 📷 截图位置：环境概览页的「环境 ID」字段

---

## 2. 创建 10 个数据库集合

进入环境 → 左侧菜单「数据库」，逐个创建以下 **10 个集合**（集合名必须与下表完全一致，与 Supabase 表名同名，方便双端互迁）：

| 集合名 | 对应 LifeOS 数据 |
|--------|-----------------|
| `tasks` | 任务（含子任务） |
| `timeline` | 时间轴事件 |
| `habits` | 习惯 |
| `habit_records` | 习惯打卡记录 |
| `reviews` | 每日复盘（记录 id 即日期） |
| `skills` | 学习技能树 |
| `notes` | 学习笔记 |
| `characters` | 角色库 |
| `moments` | 特殊事件 |
| `devices` | 设备注册表（v5.0.0 设备管理，doc id 即 deviceId） |

> 📷 截图位置：数据库集合列表，9 个集合全部创建完成的状态

说明：集合无需预定义字段，LifeOS 写入的每条文档结构为：

```json
{
  "_id": "记录 id（reviews 为日期 yyyy-MM-dd）",
  "data": { "…完整记录 JSON…" },
  "updated_at": "2026-07-20T12:00:00.000Z",
  "updated_by": "dev-xxxxxxxxxxxx",
  "deleted_at": null
}
```

## 3. 开启匿名登录

LifeOS 通过 **匿名登录** 访问云数据库（单用户场景，无需注册账号体系）：

1. 进入环境 → 左侧菜单「身份验证」→「登录方式」（或「登录授权」）
2. 找到 **匿名登录**，点击「启用」

> 📷 截图位置：登录方式列表中「匿名登录」开关已开启

---

## 4. 配置数据库安全规则

进入环境 → 左侧菜单「数据库」→「安全规则」，对上面 9 个集合分别设置。

**个人自用的两种推荐配置（二选一）：**

- **简单模式**：所有用户可读写（匿名登录用户即可读写，envId 不公开即是安全边界）：

```json
{
  "read": true,
  "write": true
}
```

- **严格模式（推荐）**：仅允许已登录（含匿名登录）用户读写，拒绝未登录访问：

```json
{
  "read": "auth != null",
  "write": "auth != null"
}
```

> 📷 截图位置：安全规则编辑框，粘贴规则后点击「发布」

注意：10 个集合都要配置。若安全规则未放开，`测试连接` 会报权限错误。

> 也可用 CLI 建集合与配规则（v5.0.0 起 devices 集合即用此法创建）：
> `tcb db nosql execute -c '[{"TableName":"devices","CommandType":"COMMAND","Command":"{\"create\":\"devices\"}"}]' -e <envId>`
> `tcb api tcb ModifySafeRule --api-version 2018-06-08 --body '{"EnvId":"<envId>","CollectionName":"devices","AclTag":"CUSTOM","Rule":"{\"read\":\"auth != null\",\"write\":\"auth != null\"}"}'`

---

## 5. 在 LifeOS 中填写配置

1. 打开 LifeOS → 设置 → 多端同步
2. 「同步后端」选择 **腾讯云 CloudBase（国内）**
3. 「CloudBase 环境 ID」填入第 1 步记录的 envId
4. 点击 **💾 保存同步配置**
5. 点击 **🔌 测试连接**：显示「✅ 连接成功，tasks 集合可访问」即配置完成
6. 点击 **🔄 立即同步**：本机数据将全量推送到 CloudBase

在每台设备上各填一次相同 envId，并给设备起名（如「手机」「家里电脑」）。

---

## 6. 常见问题

| 问题 | 排查 |
|------|------|
| 测试连接报「匿名登录」相关错误 | 控制台 → 身份验证 → 确认匿名登录已启用 |
| 测试连接报权限 / 403 | 9 个集合的安全规则是否都已配置并发布 |
| 同步后云端看不到数据 | 控制台 → 数据库 → 打开对应集合查看文档列表 |
| 切换回 Supabase 后数据不是最新 | 正常现象：两个后端数据独立。切换前的最后状态仍在，重新同步即可对齐 |

---

## 7. 费用与限额提示

- 按量计费环境下，个人同步（每次几十条文档读写）月成本通常低于 1 元
- 云数据库单次查询上限 100 条，LifeOS 同步引擎已自动分页拉全
- Web SDK 通过官方 CDN 懒加载（`static.cloudbase.net` / `imgcache.qq.com`，均为腾讯官方域名，国内直连），只有选择 CloudBase 后端时才会加载
