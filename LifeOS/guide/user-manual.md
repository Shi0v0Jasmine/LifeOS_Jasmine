## 二、第一次用要设置什么？

### 1. 给设备起个名字

打开「设置」→「多端同步」，给这台设备起个名字，比如：
- 电脑写：`我的电脑`
- 手机写：`我的手机`

这样以后在设备列表里能分清谁是谁。

### 2. 想多台设备一起用？要开同步

LifeOS 默认只存在你当前这台设备上。如果你想电脑写的任务手机也能看到，需要开同步：

1. 打开「设置」→「多端同步」
2. 同步后端选「腾讯云 CloudBase（国内）」
3. 环境 ID 填这一串：
   ```
   lifeos-d5gxoyi3o79a3518c
   ```
4. 点「保存同步配置」→「测试连接」→「立即同步」

每台要同步的设备都这么填一次，数据就会自动保持一致了。

### 3. 主设备设一台就好

如果两台设备同时改了同一条记录，系统默认保留**最新改的**；如果时间几乎一样，就听**主设备**的。建议把你最常用的电脑设为主设备：

设置 → 多端同步 → 打开「本设备为主设备」

## 三、这些功能是干嘛的？

### 📋 任务
记待办事项。可以写标题、设截止日期、分轻重缓急。重要的事可以拆成小步骤（子任务）。

### 🕐 时间轴
看今天发生了什么，像流水账一样一条一条。可以记吃了什么、学了什么、做了什么。

### ✅ 习惯打卡
比如「每天背 20 个单词」「每天运动 30 分钟」。打完卡会显示连续坚持了几天，断了会提醒你。

### 🌙 每日复盘
睡前回答四个问题：今天做了什么？哪里做得好？哪里不好？有什么想法？坚持写能看到自己的变化。

### 📚 学习日记
学东西的时候记一笔，会攒成「技能经验值」，像打游戏升级一样。

### 🎭 角色库
完成任务时会有动漫角色跳出来夸你。内置《排球少年》、Fate、EVA 里的角色，不喜欢可以在设置里关掉。

## 四、换手机/换电脑了怎么办？

1. 在新设备上打开网址
2. 打开设置 → 多端同步
3. 填和原来一样的环境 ID
4. 点「立即同步」，数据就会拉下来

> 注意：本地没同步过的数据不会自己跑到新设备上，所以一定要记得开同步。

---

## 五、设备管理（电脑上才能管）

设置 → 多端同步 → 设备管理，能看到所有登录过的设备。

- **休眠**：让某台设备暂时不同步（比如旧手机不用了）
- **唤醒**：让它恢复同步
- **删除**：让它停止同步，下次打开会提示重新授权

只有主设备能操作别的设备。

## 六、常见问题

### 手机上怎么看不到电脑上的任务？

1. 检查两台设备填的环境 ID 是不是一模一样
2. 手机上把 App 从后台彻底关掉，重新打开
3. 等几秒，或者手动点「立即同步」

### 页面好像没更新，按钮不见了？

这是缓存问题。把所有 LifeOS 的页面都关掉，再重新打开。电脑也可以按 `Ctrl + Shift + R` 强制刷新。

### 数据会丢吗？

LifeOS 先存在你自己设备上，再自动备份到云端。建议每隔一段时间去设置页点「导出数据」，下载一个备份文件存到电脑或网盘里，双保险。

### 为什么设备管理里有两个「我的电脑」？

如果你用 Chrome 和 Edge 都打开过，或者清过浏览器数据，就会生成新的设备记录。把常用的设为主设备，不常用的休眠或删除就行。
