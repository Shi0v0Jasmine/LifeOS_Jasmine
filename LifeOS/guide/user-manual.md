# LifeOS 用户手册

> 写给每天用 LifeOS 的你。不是开发文档，只看这一份就能上手。

---

## 1. LifeOS 是什么？

LifeOS 是一个**本地优先的个人生活管理系统**：任务、时间轴、习惯打卡、每日复盘、学习日记、角色激励，全部数据先存在你设备本地的 IndexedDB 里。你可以选择开启**多端云同步**，让电脑、手机、平板自动保持一致。

核心原则：
- **不登录也能用**：默认匿名同步，数据属于你自己。
- **离线可用**：没有网络时照常记录，联网后自动补同步。
- **换设备不慌**：只要配置同一个同步后端，数据会自动拉下来。

## 2. 第一次打开要做的事

### 2.1 安装为 PWA（推荐）

**电脑 Chrome**：
1. 打开 LifeOS 网址
2. 地址栏右侧点击「安装 LifeOS」图标（或菜单 → 保存并分享 → 安装页面为应用）
3. 安装后它像一个原生 App，可从桌面/开始菜单打开

**手机**：
1. 用手机浏览器（Chrome/Safari）打开 LifeOS
2. Safari：底部分享按钮 →「添加到主屏幕」
3. Chrome：菜单 →「添加到主屏幕」

### 2.2 开启多端同步

1. 打开 **设置** 页面
2. 找到「多端同步」卡片
3. 给设备起个名字，例如：
   - 电脑：`Jasmine 的电脑`
   - 手机：`Jasmine 的手机`
4. 选择同步后端：
   - **腾讯云 CloudBase（国内推荐）**：填入 `envId`
   - **Supabase（国际）**：填入 Project URL + anon key
5. 点击「💾 保存同步配置」→「🔌 测试连接」→「🔄 立即同步」

> 📌 同步不会自动迁移旧本地数据到云端：保存配置后点一次「立即同步」，本机数据才会全量推上去。

### 2.3 主设备设置

冲突时（同一任务两边都改了）系统默认**最新修改赢**；如果时间差 < 2 秒，则由**主设备**裁决。

- 建议把你最常用的设备（比如电脑）设为**主设备**：设置 → 多端同步 → 打开「本设备为主设备」
- 主设备才能休眠/唤醒/删除其他设备
- **只设一台主设备**即可

## 3. 各模块速览

### 3.1 任务（Tasks）

- 创建任务：标题 + 截止日期 + 象限（紧急/重要）
- 子任务：点开任务可添加子步骤
- 循环任务：设置每天/每周重复，系统会自动生成「今天副本」
- 完成：点击左侧圆圈，角色激励弹窗会出现（可在设置里关闭）

### 3.2 时间轴（Timeline）

- 按天查看事件流
- 可记录普通事件、循环事件、番茄钟事件
- 顶部可切换日/周/月/统计视图

### 3.3 习惯（Habits）

- 新建习惯，选择频率（每天/每周几次）
- 首页 Dashboard 和习惯页可打卡
- 连续打卡会显示 streak（连续天数）
- 支持「补打卡」：如果昨天忘了，可在习惯页补上

### 3.4 每日复盘（Review）

- 每天回答 DID / GOOD / BAD / THOUGHTS 四个问题
- 可让 AI 用 GRAI 框架分析（需要配置 AI API）
- 复盘记录按日期保存

### 3.5 学习日记（Learning）

- 记录学习内容，自动累积为「技能树」经验值
- 给学习内容打 hashtag，方便分类
- 在时间轴记录学习时间也会给技能树加经验

### 3.6 角色库（Characters）

- 内置《排球少年》、Fate、EVA、柯南等 50+ 角色
- 完成任务/打卡/升级时，角色会弹出鼓励台词
- 可上传头像、编辑性格标签和台词风格

## 4. AI 功能

设置页可配置 AI：

1. Base URL
2. API Key
3. 模型名称

目前默认使用 mimo-v2.5-pro（通过 CloudBase 云函数代理解决浏览器跨域）。支持的功能：

- **自然语言拆任务**：把一段话（如「下周三要交论文，周四要洗衣服」）拆成多个任务
- **复盘分析**：用 GRAI 框架分析每日复盘
- **角色对话**：和角色库里的角色聊天

> 💡 如果 AI 连不上，检查设置页代理配置：留空 = 使用默认 CloudBase 代理；`-` = 强制直连；其他 URL = 自定义代理。

## 5. 数据安全与备份

### 5.1 自动云端同步

开启同步后，数据会增量备份到 CloudBase/Supabase。只要同步成功，换设备登录同一后端即可恢复。

### 5.2 手动导出备份

设置页 →「导出数据」：下载一个 JSON 备份文件到本地。建议定期导出一份放到硬盘或网盘。

### 5.3 导入数据

设置页 →「导入数据」：选择 JSON 备份文件。

- **合并**：与现有数据合并（同名记录按最新时间保留）
- **覆盖**：清空本地，用备份替换

> ⚠️ 导入前建议先导出当前数据，以防误操作。

## 6. 设备管理（v5.0.0）

设置 → 多端同步 → 设备管理：

- 列出所有在该云端注册过的设备
- 主设备可操作其他设备：
  - **休眠**：被休眠的设备会暂停同步（适合暂时不用某设备）
  - **唤醒**：恢复同步
  - **删除**：被删除的设备下次同步时会停止并提示重新授权
- 本设备标记、主设备标记会显示在列表里

> ⚠️ 删除是「应用层吊销」：因为用的是匿名登录，服务端无法真正吊销凭证，但被删除的设备会自觉停止同步。

## 7. 常见问题

### Q1：手机上找不到数据？

1. 确认手机和电脑填的是**同一个** CloudBase envId 或 Supabase 配置
2. 手机上彻底杀掉 PWA/浏览器，重新打开
3. 等它自动同步一次（或手动点「立即同步」）

### Q2：设备管理里出现很多「我的电脑」？

每台浏览器/每个 Chrome 配置文件都会产生独立设备码。如果你用 Chrome 和 Edge 都打开过，就会看到两条。建议给常用浏览器设为主设备。

### Q3：换电脑后设备码变了，主设备要重设？

当前版本（v5.0.0）确实如此。**v5.1.0 将加入账号密码登录**，登录后主设备权限会跟随账号，换浏览器登录即可恢复主设备身份，无需重设。

### Q4：PWA 更新后页面还是旧的？

LifeOS 使用 Service Worker 缓存。如果看到新功能异常或按钮缺失：

1. 关掉所有 LifeOS 标签页/PWA
2. 重新打开
3. 还不行就 `Ctrl + Shift + R`（电脑）或杀掉 PWA 重开（手机）

### Q5：同步失败怎么办？

设置页会显示最近错误。常见原因：

- 网络问题：等网络恢复后会自动重试
- CloudBase 匿名登录未开启：去腾讯云控制台开启
- 安全规则未配置：10 个集合都要配 `auth != null`
